# Project Roadmap

## Phase 1
**Contract Engine**
- Implementing intent extraction and strict JSON parsing.

## Phase 2
**Verification**
- Building the automated QA layer using GroundingDINO and Florence-2.

## Phase 3
**Benchmarking**
- Establishing the baseline failure rates of monolithic models.

## Phase 4
**Repair Loops**
- Autonomous agents correcting Scene Graphs based on Verification Reports.

## Phase 5
**Video Consistency**
- Extending the contract temporally for multi-frame generation.

## Phase 6
**Agentic Generation**
- Exposing the API for LLM agents to use as a fully autonomous visual cortex.
